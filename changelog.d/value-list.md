- **New:** The browser's Value tab lists everything you could still sell, one
  row per item, character and location, with the price source, total value,
  gain over the vendor and binding; every column sorts. Prices come from Oribos
  Exchange (region or realm), Auctionator, TradeSkillMaster or the vendor,
  automatically the highest or one source you pick. Worn gear, auctions and
  (unless shown) equipment set items stay out; guild banks join only when
  selected.
- **New:** Options for the value list: which sources the automatic price
  compares, whether auction prices lose the auction house's 5% cut, and which
  TradeSkillMaster price it reads.
- **Enhanced:** Stored items remember when they are warbound until equipped,
  which can be sold to a vendor only.
